# Pomodoro Timer

A productivity application built with Python and Tkinter based on the Pomodoro technique.

## Features
- 25-minute work sessions followed by 5-minute short breaks.
- 20-minute long break after 4 work sessions.
- Clean and simple graphical user interface.
- Checkmarks to track completed work sessions.

## How to Run
1. Ensure you have Python installed.
2. Clone this repository.
3. Run the script:
   ```bash
   python main.py
   ```
